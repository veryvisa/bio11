Concept slides概念幻灯

1/11

Is a virus alive?病毒是生命吗？

A virus has genetic material and evolves, but it has no cells, no metabolism of its own and cannot reproduce alone. Most biologists place it on the edge of life.病毒有遗传物质，也会演化，但没有细胞，没有自己的新陈代谢，也不能独立繁殖。多数生物学家把它放在生命的边缘。

2/11

Parts of a virus病毒的结构

Genetic material (DNA or RNA) sits inside a protein coat called a capsid. Some viruses add an outer envelope. Spikes help them attach to a host cell.遗传物质（DNA 或 RNA）在称为衣壳的蛋白质外壳里；有的病毒还有外层包膜；刺突帮助它们附着在宿主细胞上。

3/11

Lytic cycle裂解周期

The virus attaches, injects its DNA, makes many copies using the host cell, and bursts it open. The new viruses go on to infect other cells.病毒附着、注入 DNA，利用宿主细胞复制出许多拷贝，再使细胞破裂；新病毒继续感染其他细胞。

4/11

Lysogenic cycle溶原周期

The viral DNA joins the host chromosome and is copied each time the cell divides. A trigger, such as stress, can switch it to the lytic cycle.病毒 DNA 整合进宿主染色体，随细胞每次分裂被复制；压力等诱因可以让它转入裂解周期。

5/11

Anatomy of a bacterium细菌的结构

A bacterium has a cell wall, a cell membrane, ribosomes and a ring of DNA in the nucleoid. It has no nucleus. Some have a capsule, flagella or pili.细菌有细胞壁、细胞膜、核糖体，DNA 成环状位于拟核；没有细胞核。有些还有荚膜、鞭毛或菌毛。

6/11

Three bacterial shapes细菌的三种形状

Cocci are round, bacilli are rods, and spirilla are spirals. Shape is one clue for identifying bacteria.球菌是圆的，杆菌是棒状，螺旋菌是螺旋形。形状是鉴定细菌的一条线索。

7/11

How bacteria reproduce细菌如何繁殖

Binary fission makes two identical cells, so bacteria can multiply very fast. Conjugation does not make new cells; it passes DNA between cells.二分裂产生两个相同的细胞，所以细菌能很快增多；接合不产生新细胞，只在细胞间传递 DNA。

8/11

Helpful bacteria有益的细菌

Decomposers recycle dead matter. Nitrogen fixers feed plants. Cyanobacteria add oxygen. Gut bacteria help digestion and make some vitamins.分解者循环利用死亡物质；固氮菌给植物提供氮；蓝细菌释放氧气；肠道细菌帮助消化并合成部分维生素。

9/11

Bacteria or archaea?细菌还是古菌？

Both are single-celled prokaryotes with no nucleus. Bacterial walls contain peptidoglycan; archaeal walls do not. Archaea are often found in extreme places.两者都是没有细胞核的单细胞原核生物。细菌的细胞壁含肽聚糖，古菌的不含。古菌常见于极端环境。

10/11

Antibiotics and viruses抗生素与病毒

Antibiotics attack bacterial structures such as the cell wall. Viruses have none of these, so antibiotics do nothing against a cold or flu.抗生素攻击细菌的结构，如细胞壁；病毒没有这些结构，所以抗生素对感冒和流感无效。

11/11

Vaccines疫苗

A vaccine shows the immune system a harmless piece of a germ. The body builds memory cells and can respond quickly if the real germ arrives.疫苗让免疫系统接触无害的病原体片段，身体产生记忆细胞，真正的病原体到来时就能快速应对。

Test practice测验练习

1. Which of these is NOT a feature of viruses?

  1. Genetic material
  2. A protein coat
  3. Their own ribosomes
  4. Need a host cell
Answer

C · Viruses have no ribosomes. They use the host's.

2. Viruses are called obligate parasites because they

  1. eat other cells
  2. can reproduce only inside a host cell
  3. live in soil
  4. make antibiotics
Answer

B · They must use a host cell to reproduce.

3. In which cycle does the host cell burst quickly?

  1. Lysogenic
  2. Lytic
  3. Binary fission
  4. Conjugation
Answer

B · Lysis means bursting open.

4. In the lysogenic cycle, viral DNA

  1. is destroyed
  2. joins the host's DNA and is copied with it
  3. makes the host burst at once
  4. becomes a plasmid
Answer

B · It hides in the host chromosome.

5. A virus that infects bacteria is called a

  1. bacillus
  2. bacteriophage
  3. prion
  4. spirillum
Answer

B · Bacterio- = bacteria, -phage = eater.

6. Antibiotics are useful against

  1. bacterial infections
  2. colds
  3. influenza
  4. all viruses
Answer

A · Antibiotics target bacteria, not viruses.

7. Which structure is found in a bacterium?

  1. Nucleus
  2. Mitochondrion
  3. Nucleoid
  4. Chloroplast
Answer

C · The nucleoid is the DNA region without a membrane.

8. A bacterium shaped like a rod is a

  1. coccus
  2. bacillus
  3. spirillum
  4. virus
Answer

B · Bacillus = rod.

9. How do bacteria reproduce?

  1. Mitosis
  2. Binary fission
  3. Fertilization
  4. Budding of spores only
Answer

B · They copy DNA and split in two.

10. Conjugation in bacteria

  1. makes two new cells
  2. passes DNA between two cells
  3. kills the host
  4. is a type of binary fission
Answer

B · It is a DNA transfer, not reproduction.

11. Endospores help bacteria

  1. move
  2. survive harsh conditions
  3. make food
  4. pass DNA
Answer

B · They are tough dormant forms.

12. Bacteria that turn nitrogen gas into ammonia are doing

  1. photosynthesis
  2. nitrogen fixation
  3. decomposition
  4. conjugation
Answer

B · Plants can use the ammonia.

13. Which is a difference between bacteria and archaea?

  1. Only bacteria are prokaryotes
  2. Bacterial walls contain peptidoglycan; archaeal walls do not
  3. Only archaea have a nucleus
  4. Only bacteria have DNA
Answer

B · Cell wall chemistry is one key difference.

14. An organism that lives in hot springs is a

  1. halophile
  2. thermophile
  3. methanogen
  4. cyanobacterium
Answer

B · Thermo = heat.

15. Which is an example of mutualism?

  1. A tapeworm in a gut
  2. Gut bacteria helping digest food while living in the gut
  3. A virus infecting a cell
  4. A bacterium causing strep throat
Answer

B · Both sides benefit.
